# MCU Project Guide

## Overview

This repository contains the firmware project for the **Microchip PIC24EP128MC206** 16-bit microcontroller, configured with MPLAB Code Configurator (MCC) and buildable via standard GNU Make and VS Code.

---

## Hardware & Toolchain Specifications

- **Target Device**: `PIC24EP128MC206`
- **Compiler**: Microchip XC16 (`v2.10`) — located at `/opt/microchip/xc16/v2.10/bin/xc16-gcc`
- **Device Family Pack (DFP)**: `dsPIC33E-GM-GP-MC-GU-MU_DFP` (`v1.7.401`) — located at `/opt/microchip/mplabx/v6.35/packs/Microchip/dsPIC33E-GM-GP-MC-GU-MU_DFP/1.7.401`
- **Build System**: GNU Make with MPLAB X generated makefiles (`Makefile`, `nbproject/Makefile-default.mk`)

---

## Build Instructions

### Command Line

- **Build (Production Hex/ELF)**:
  ```bash
  make
  ```
- **Build (Debug ELF with `-D__DEBUG`)**:
  ```bash
  make TYPE_IMAGE=DEBUG_RUN
  ```
- **Clean Build Artifacts**:
  ```bash
  make clean
  ```
- **Clean and Rebuild**:
  ```bash
  make clean && make
  ```

### VS Code

- **Default Build**: Press `Ctrl+Shift+B` (or run `Terminal: Run Build Task` -> `Build (Production)`).
- **Other Tasks**: Press `Ctrl+Shift+P` -> `Tasks: Run Task` -> choose:
  - `Build (Production)`
  - `Build (Debug)`
  - `Clean`
  - `Clean and Rebuild (Production)`
  - `Clean and Rebuild (Debug)`
- Compiler errors and warnings are parsed via the `$gcc` problem matcher directly into the VS Code Problems panel.

## Project Structure
- `main.c`: Application entry point (`main()`) initializing FreeRTOS tasks and starting scheduler.
- `al.h`: Abstraction Layer providing FreeRTOS and peripheral wrappers adhering to project naming standards.
- `led.c` / `led.h`: Universal normalized LED output interface backed by driver callbacks.
- `FreeRTOSConfig.h`: FreeRTOS kernel configuration (1 kHz tick rate, 69.09375 MHz CPU instruction clock, preemption enabled, 4KB heap).
- `FreeRTOS/`: FreeRTOS V11 kernel and PIC24/dsPIC port files:
  - `FreeRTOS/Source/`: Kernel implementation files (`tasks.c`, `queue.c`, `list.c`, `timers.c`, `event_groups.c`, `stream_buffer.c`).
  - `FreeRTOS/Source/include/`: Kernel API header files (`FreeRTOS.h`, `task.h`, etc.).
  - `FreeRTOS/Source/portable/MemMang/`: Memory management (`heap_4.c`).
  - `FreeRTOS/Source/portable/MPLAB/PIC24_dsPIC/`: Hardware port files (`port.c`, `portmacro.h`, `portasm_PIC24.S`).
- `mcc_generated_files/`: Peripheral drivers and system configurations generated by MCC:
  - `system.c` / `system.h`: System clock initialization, oscillator, and CORCON setup.
  - `clock.c` / `clock.h`: PLL and clock frequency configurations.
  - `pin_manager.c` / `pin_manager.h`: Pin direction, PPS (Peripheral Pin Select), and analog/digital modes.
  - `oc1.c` - `oc4.c`: Output Compare / PWM modules.
  - `interrupt_manager.c`: Global and peripheral interrupt priorities.
  - `traps.c`: Hardware exception and error trap handlers.
  - `reset.c`: Reset cause handling.
  - `mcc.c` / `mcc.h`: Master MCC driver includes.
- `mcu.mc3`: MCC configuration save state.
- `nbproject/`: MPLAB X project configuration, build macros, and tool paths.
- `.vscode/`: VS Code workspace configuration:
  - `tasks.json`: Build, clean, and rebuild tasks.
  - `c_cpp_properties.json`: C/C++ IntelliSense include paths and macros for XC16.
  - `settings.json`: Workspace settings and file associations.
  - `extensions.json`: Recommended extensions for MPLAB and C/C++.
